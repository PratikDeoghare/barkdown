Text #

Paragraphs are separated by blank lines. Inside them you can write bold, italic, emphasis, inline code or inline code, highlights, struck text, H2O, E = mc2, keys like Ctrl + C, and abbreviations such as HTML. A line break
goes like this. The characters #, {, } and backticks go between backticks.

Links take the URL first: the brashtag repository. Links to other posts use their slug, like Welcome to barkdown, and are checked when the site is built. A URL with a fragment goes between backticks: learning Go.

Let us change our traditional attitude to the construction of programs: Instead of imagining that our main task is to instruct a computer what to do, let us concentrate rather on explaining to human beings what we want a computer to do.

— Donald E. Knuth, Literate Programming

Lists #

  • Each line is an item.
  • A line may start with a dash, as in Markdown.
    • A nested list sits on a line of its own.
  • Items can hold markup and code, with commas.
  1. First
  2. Second
  3. Third

The comma separated list of the original barkdown still works, and like every list it is a block of its own:

  • one
  • two
  • three

def fib(n):
    """Return the n-th Fibonacci number."""
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
